纽约 REAL ID 条件检查

已经考虑好 6 Points？再检查 REAL ID 还需要满足的几个主要条件。

① 6 Points
② 身份 / 合法身份
③ Social Security
④ 纽约地址证明

REAL ID 需要2份不同类型、不同来源的合格纽约地址证明，显示当前地址；银行 / 水电账单应在1年内，电子账单需打印，P.O. Box 不接受。

选择上面 4 项后查看结果。

REAL ID 比普通 Standard 多什么？

纽约 DMV 当前要求 REAL ID 申请人准备 Social Security 相关证明、公民身份或合法身份、2 份纽约州居住证明，并满足 6 Points Proof of Name。Standard 驾照/Permit 的要求不同，通常是出生日期证明、1 份纽约州居住证明和 6 Points。

没有 SSN 可以办 REAL ID 吗？

不要把“没有社安卡”和“完全没有符合要求的 Social Security 文件”混为一谈。ID-44 列有符合条件的 Social Security Ineligibility Letter；但“从未获得 SSN”的 NSS-1 / NSS-1A 声明明确不能用于 REAL ID。具体情况应按最新 ID-44 核对。

中国护照、工卡可以直接判断能办 REAL ID 吗？

不能只看证件名称。REAL ID 要求公民身份或 lawful status，外国护照、EAD、I-94 等需要按 DMV 对应文件类别和有效状态核对。页面因此把“不确定”保留下来，不会因为你有一本护照或一张工卡就直接显示合格。

为什么一定要 2 份纽约地址证明？

这是 REAL ID 与 Standard 常见区别之一。用于居住证明的文件需要符合 DMV 对姓名、当前纽约地址、日期和文件类型的要求；电子账单需要按官方要求打印。

全名与原件也要核对

带原件或签发机构认证件；除明确允许外不接受过期文件。外国文档需认证英文翻译；改名需带连接全部姓名的原件 / 认证证明。达到6分仍须确认所选文件可用于 REAL ID，外国驾照不能用于 REAL ID 的出生日期证明。

下一步

如果 4 项主要条件都满足，再进入“材料清单”确认去 DMV 要带的具体原件；如果 6 Points 还不确定，先回到 6 Points 计算器。
