本清单用于普通非商业驾照 / Learner Permit。Non-Driver ID 另有规则：Standard 也需 citizenship / lawful status，且不要求居住证明；不要套用 Green Light Law。

材料清单怎么用？

这个页面不再帮你算 6 Points。如果不知道自己的文件够不够 6 分，请先用「6 Points」工具；如果不知道能不能办 REAL ID，请用「REAL ID检查」；如果不知道 Standard、REAL ID、Enhanced 应该选哪个，请用「我能办哪种」。

纽约 DMV 最新 ID-44 要求：Standard License / Permit 通常需要 1 份纽约州居住证明；REAL ID 和 Enhanced 需要 2 份。用于地址证明的文件应显示当前纽约地址，P.O. Box 不接受；电子账单和 e-bill 需要打印。每一种来源或类型通常只能使用一份。

Standard

准备可接受的出生日期证明、至少 6 Points 的姓名证明，以及 1 份纽约州居住证明。Standard 对 Social Security 的路径与 REAL ID 不完全相同，没有 SSN 的申请人应按 ID-44 的 Standard 规则准备相应声明或材料。

REAL ID

除 6 Points 外，还要准备符合要求的 Social Security 证明、公民身份或 lawful status 证明，以及 2 份纽约州居住证明。没有资格获得 SSN 的特定申请人，需要符合要求的 SSA 不符合资格信及相应 DHS 文件。

Enhanced

Enhanced 仅限符合条件的美国公民，需准备美国公民身份证明、Social Security 相关证明、2 份纽约州居住证明并满足 6 Points。Enhanced 另加 $30 费用。
