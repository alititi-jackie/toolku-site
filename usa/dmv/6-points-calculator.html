检查结果

纽约 DMV 6 Points 是什么？

第一次申请纽约州 Standard Learner Permit或普通非商业 Driver License 时，DMV 会按可接受文件核对姓名、出生日期和身份，并要求 Proof of Name 达到规定积分。这个工具把复杂表格整理成“身份证明 → 纽约地址证明 → 其它加分证明”三步，方便刚来美国的华人快速检查自己手上的材料。

中国护照可以用来申请纽约驾照吗？

有效外国护照可按 Green Light Law用于 Standard普通非商业驾照 / Permit的4分材料。REAL ID需要合格 Visa / I-94或 I-551等配套文件；没有移民文件不代表不能申请 Standard，但不能据此通过 REAL ID检查。

纽约考驾照一定要有 Social Security Card 吗？

不一定。没有 SSN 的申请人也可能按 DMV 规定办理 Standard 证件，但必须按自己的实际情况完成相应声明或证明。社安卡如果符合要求，可以作为 Proof of Name 的计分文件。

银行账单是不是必须的？

不是。银行账单只是常见的纽约地址证明之一。工资单、符合要求的 Utility Bill、W-2 等也可能用于证明当前纽约州地址。页面不会强制要求你一定有银行卡或银行账单。

为什么已经 6 分还可能不够？

6 Points 与地址证明不是同一个条件。即使身份和其它加分证明已经达到 6 分，如果没有符合要求的纽约州地址证明，主要材料仍没有准备齐。Standard 通常至少需要一份符合要求的纽约州地址证明。

同一家银行的文件能重复算吗？

纽约 DMV 有 One Proof Per Source or Type 的限制。同一种证明或同一来源的多份材料不能简单重复使用。工具会避免已知的同类型文件重复计分；银行账单、银行卡和信用卡在本简化工具中保守地只计1分，避免未知来源重复累加；其余材料也须自行核对是否同来源。

使用前注意

本工具面向 Standard Permit / Driver License 常见文件准备场景，主要用于快速自查，不代替 DMV 最终审核。REAL ID 和 Enhanced 的地址及身份要求更严格，请使用本站对应的 REAL ID 工具进一步检查。
