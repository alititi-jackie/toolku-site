🆔 REAL ID 文件检查器

逐项检查你是否带齐了申请 REAL ID 所需的所有文件，避免白跑一趟 DMV

REAL ID 是什么？ 从 2025 年 5 月起，美国联邦机构（包括机场安检）将只接受 REAL ID 认证的驾照和身份证。如果你还没有 REAL ID，建议尽早申请。纽约州的 REAL ID 需要在 DMV 柜台亲自办理。

请勾选文件并点击"检查文件"
注意事项 1. 所有文件必须是原件或认证副本，复印件不被接受。
2. 地址证明文件必须是最近 60 天内签发的。
3. 如姓名变更（如结婚），还需提供结婚证等法律文件。
4. 建议提前在 DMV 官网预约，减少排队时间。
