📋 DMV 证件准备清单

去 DMV 之前，逐项打勾确认文件齐全，避免白跑一趟

  • 基本信息
  • 纽约州驾照或 ID 卡（如已有）
  • 社会安全号 (SSN Card 或 W-2)
  • 出生证明 (Birth Certificate) 认证副本
  • 护照 (Passport) 或绿卡 (Green Card)
  • 地址证明（需 2 份）
  • 水电费账单 (Utility Bill) — 最近 60 天内
  • 银行/信用卡账单 — 最近 60 天内
  • 租约 / 物业账单 / 税单
  • 学校成绩单 / 录取通知书 (学生适用)
  • 驾照考试（首次申请）
  • 完成 5 小时 Pre-Licensing Course 证书 (MV-278)
  • Parental Consent Form (18岁以下)
  • 视力检查表 (若未通过 DMV 现场测试)
  • 续照 / 换照
  • 旧驾照原件
  • 交通安全课程证书 (如适用)
  • 体检报告 (60岁以上或特定情况)
  • 费用
  • 支票/汇票/现金 (驾照费用约 $80 左右，以 DMV 为准)
  • 信用卡 (部分 DMV 办公室接受)
温馨提示 1. 所有文件必须是原件或认证副本，复印件通常不被接受。
2. 地址证明文件必须是最近 60 天内签发的。
3. 建议提前在 DMV 官网预约 (online.dmv.ny.gov)，减少排队时间。
4. 首次申请 Learner Permit 无需预约，可直接前往任何 DMV 办公室。
