# ToolKu

Multilingual everyday tools at https://toolku.com.

Based on [OmniTools](https://github.com/iib0011/omni-tools), MIT licensed.
Upstream revision: `3bbca2fdc076d972ff21144e58dd6ef0480655f0`. Original copyright retained in LICENSE.

## Development

Node 22+, `npm ci`, `npm run dev`.
`npm run build` typechecks, bundles and creates static route entry points for GitHub Pages.
Pushes to main deploy the tested dist directory using GitHub Pages.

## Brand

ToolKu name, logo and favicon are retained from the original ToolKu site.
Translations are from upstream, with English fallback for untranslated strings.
